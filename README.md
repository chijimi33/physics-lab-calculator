# 大学物理学実験 計算支援

大学の物理学実験レポート作成を補助するWebアプリです。
測定値を入力すると、平均値、残差、標準誤差、誤差伝播、有効数字を考慮した表示、グラフ、CSV出力などを確認できます。

本番URL: https://physics-lab-calculator.vercel.app/

## 対応している実験

- 1-1「金属棒の密度の測定」
  - 直径、長さ、質量から密度と誤差を計算
  - 文献値との比較
- 1-2「落下の実験」
  - 位置と時刻から速度、加速度、重力加速度を計算
  - 自由落下、抵抗あり落下の表とグラフ表示
- 1-3「単振り子」
  - 振り子の長さ、周期、振幅依存性から重力加速度を計算
  - 回帰結果とグラフ表示

## 基本的な使い方

1. トップページで実験を選択します。
2. 左側の入力表に、実験で測定した値を入力します。
3. 右側の「入力確認」で不足や入力ミスの可能性を確認します。
4. 「計算結果」で平均値、標準誤差、最終結果などを確認します。
5. 必要に応じて「グラフ」「使用した式」を確認します。
6. レポート作成用に、結果のコピー、CSV出力、PNG出力を利用できます。

入力内容は実験ごとにブラウザのlocalStorageへ保存されます。
共有PCで使う場合は、使用後に「入力をリセット」を押してください。

## 注意事項

このツールは計算補助用です。
提出前に、計算結果を必ず授業資料、実験書、担当教員の指示、自分の計算と照合してください。

- 授業で指定された単位、丸め規則、誤差評価方法を優先してください。
- 計算内部では丸めず、表示時のみ有効数字や誤差桁に合わせて丸めています。
- 表の中間値は、選択した表示有効数字より1桁多く表示します。
- グラフや回帰結果は、入力値の妥当性確認にも使ってください。

## 開発・確認方法

依存関係をインストールします。

```bash
npm install
```

開発サーバーを起動します。

```bash
npm run dev
```

テストを実行します。

```bash
npm test
```

本番ビルドを確認します。

```bash
npm run build
```

PowerShellの実行ポリシーで `npm` が止まる場合は、`npm.cmd` を使って実行してください。

```powershell
npm.cmd run dev
npm.cmd test
npm.cmd run build
```

## 技術構成

- Next.js App Router
- TypeScript
- Tailwind CSS
- KaTeX / react-katex
- Client-side only
- Vercel deploy

実験ページは共通ルーティング `/experiments/[slug]` で表示しています。
新しい実験は `src/experiments` に実験定義を追加し、`src/experiments/index.ts` に登録する構成です。
